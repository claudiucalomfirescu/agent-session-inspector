llm-proxy-firewall · explainer

A checkpoint between your agents and the LLM

The logging proxy from llm-proxy-log, plus a firewall. It reads what each agent sends and what the LLM answers, and decides: let it through, flag it, or close the conversation and answer in the LLM's place.

Three possible outcomes for every message

info

Noted

"How do I reset my password?" mentions a sensitive subject. It is recorded in signals and forwarded as normal.

warning

Flagged, still forwarded

"They are completely useless. Draft a reply anyway." The reply carries X-Firewall: warning. Three warnings on one topic in one session become a block.

block

Closed

"The staging password is Leaf!2026dev." The request never reaches the provider. The agent gets an ordinary answer saying the session is closed, with a reference an administrator can look up.

The agent is where policy gets broken

Staff type things into agents

A customer list "for my side project", a password to save a lookup, a rude line about a customer. The agent obediently passes it on.

The provider enforces its rules, not yours

It will not stop your price list going to a personal Gmail. Your policy only exists in a PDF.

Every agent would need its own checks

Different teams, different frameworks, same rules to apply. One place every call passes is the only place that sees all of them.

Words alone misfire

"I can't share passwords" contains the word password. An agent refusing a bad request must not be blocked for repeating it. Intent and stance matter.

Your policy

topics:
  credential_sharing:
    title: Credential sharing
    policy: Logins are personal.
    intent: Someone shares a password…
    rules:
      - id: cred-secret-in-text
        level: block
        hard: true
        any: ['password\s*(is|:)\s*\S{4,}']

Save as my_topics.yaml, run with FIREWALL_TOPICS=my_topics.yaml. A rebuild in another language starts from SPEC.md and P-REBUILD in PROMPTS.md.

Built with Prax Systems: GOAL, SPEC, PROMPTS and tests ship with the code. A tripwire with an audit trail, not a guarantee: rules miss paraphrases and an LLM misjudges intent. Keys: Space play/pause, ← → step, 1–5 scenes.
