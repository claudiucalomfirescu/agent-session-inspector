# llm-session-console

> A local web console that drills down from all traffic to one user, day, session, message and firewall event, with a 3D galaxy view.

🚧 **Skeleton.** Being built on branch `split` following [Prax Systems](../prax-systems/METHOD.md).
Copy the files from [../prax-systems/templates/](../prax-systems/templates/), fill them, and run
`python3 tools/prax_check.py . --level silver` (a vendored copy of the Prax checker) until it passes.

See [../MASTER_PLAN.md](../MASTER_PLAN.md) for scope.
