# Goal · echo-log

## Pitch
Echo a message back and record that it happened.

## The problem
The Prax checker needs a tiny, known-good repository to test against; real repos change too often.

## Success looks like
1. `prax_check.py examples/minimal --level silver` passes.
2. A reader sees every required file filled in at its smallest useful size.

## Non-goals
Anything useful beyond being an example.
